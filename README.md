# Miguel Nyobole Personal Portfolio
## Project Overview
This project is a personal portfolio website for Miguel Nyobole, a web designer from Pretoria.
## Key Features
- Responsive design
- Bootstrap template
- Customizable sections for about, services, and contact information
## Tech Stack
- HTML
- CSS
- Bootstrap
- Google Fonts
## Installation
To install and run this project, simply clone the repository and open the index.html file in a web browser.
## Usage
- Navigate to the different sections of the website using the navigation bar
- Customize the content and styles to fit your personal brand
## Environment Variables
No environment variables are required to run this project.
